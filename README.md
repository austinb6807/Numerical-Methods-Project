# Numerical-Methods-Project
Austin Brzek, Galen Lee, Benjamin Sasson, Jeffrey Rou, and Jack Whitesal Numerical Methods project; Utilizing Euler, Improved Euler, and RK4 to model heat transfer in pipe fluid flow



To run our code:
1. clone the git repository
2. Once in the cloned repository, create and set up a virtual environment
    Open a bash terminal and input the following commands:
        python -m venv .venv
        source .venv/Scripts/activate

2. in the terminal, run pip install -r "requirements.txt"
