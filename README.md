# Numerical-Methods-Project
Austin Brzek, Galen Lee, Benjamin Sasson, Jeffrey Rou, and Jack Whitesal Numerical Methods project; Method of Characteristics for the design of a shock-free converging-diverging rocket



Sources:
https://innovationspace.ansys.com/courses/courses/internal-compressible-flows/lessons/method-of-characteristics-lesson-6/



To setup your git repository:
1. create and set up a virtual environment
    Open a bash terminal and input the following commands:
        python -m venv .venv
        source .venv/Scripts/activate

2. in the terminal, run pip install -r "requirements.txt"
